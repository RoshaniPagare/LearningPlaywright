# VS Code Keyboard Shortcuts for Windows

## General
| Action | Shortcut |
|---|---|
| Command Palette | Ctrl + Shift + P |
| Quick Open | Ctrl + P |
| Open Settings | Ctrl + , |
| Toggle Sidebar | Ctrl + B |
| Toggle Panel | Ctrl + J |
| Toggle Terminal | Ctrl + ` |
| New Terminal | Ctrl + Shift + ` |
| Save | Ctrl + S |
| Save All | Ctrl + Shift + S |
| Close Editor | Ctrl + W |
| Close All Editors | Ctrl + Shift + W |
| Split Editor | Ctrl + \ |
