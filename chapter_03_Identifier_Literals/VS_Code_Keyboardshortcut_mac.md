# VS Code Keyboard Shortcuts for Mac

## General
| Action | Shortcut |
|---|---|
| Command Palette | Cmd + Shift + P |
| Quick Open | Cmd + P |
| Open Settings | Cmd + , |
| Toggle Sidebar | Cmd + B |
| Toggle Panel | Cmd + J |
| Toggle Terminal | Ctrl + ` |
| New Terminal | Shift + Cmd + ` |
| Save | Cmd + S |
| Save All | Option + Cmd + S |
| Close Editor | Cmd + W |
| Close All Editors | Option + Cmd + W |
| Split Editor | Cmd + \ |

| Action | Shortcut |
|---|---|
| Undo | Cmd + Z |
| Redo | Shift + Cmd + Z |
| Cut | Cmd + X |
| Copy | Cmd + C |
| Paste | Cmd + V |
| Select All | Cmd + A |
| Delete Line | Shift + Cmd + K |
| Duplicate Line | Shift + Option + Down |
| Move Line Up | Option + Up |
| Move Line Down | Option + Down |
| Indent Line | Cmd + ] |
| Outdent Line | Cmd + [ |
| Comment Line | Cmd + / |
| Block Comment | Option + Shift + A |
