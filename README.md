## Getting started / Installation

Prerequisites:

- Node.js (>= 16)
- npm or yarn

Quick setup:

1. Clone the repo:

   git clone https://github.com/RoshaniPagare/LearningPlaywright.git
2. Install dependencies:

   npm install
   
   or

   yarn install
3. Install Playwright browsers (if using Playwright tests):

   npx playwright install

## How to run tests

- Run all Playwright tests:

  npx playwright test

- Run a single test file:

  npx playwright test tests/example.spec.js

## How to use

1. Open the chapter folders in order.
2. Read the JavaScript examples.
3. Practice the examples in your own editor.
4. Use the shortcut notes to improve your VS Code workflow.
5. Explore the Playwright examples in Chapter 04 to try automated browser tests.
